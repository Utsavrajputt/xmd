# docs/

`screenshot-carousel.gif` here is a generated file — built from
`fastlane/metadata/android/en-US/images/phoneScreenshots/` by
`scripts/generate-screenshot-carousel.sh`, either locally or via
`.github/workflows/screenshot-carousel.yml`. Don't hand-edit it; add/change
screenshots in that folder and re-run the script (or push, and let CI
regenerate it) instead.
