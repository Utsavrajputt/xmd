# Screenshots

Drop real screenshots here using the filenames below — the numeric prefix
controls left-to-right order in the auto-generated README carousel
(`docs/screenshot-carousel.gif`, built by
`.github/workflows/screenshot-carousel.yml` via
`scripts/generate-screenshot-carousel.sh`).

This folder is also the standard `fastlane`/F-Droid metadata location, so
the same files double as Play Store / F-Droid listing screenshots later —
no separate export needed.

| Filename | Shows |
|---|---|
| `01-home-screen.png` | Home / shortcuts grid |
| `02-downloads-queue.png` | Downloads/Queue with an active multi-connection download |
| `03-add-download-dialog.png` | Add Download dialog |
| `04-torrent-download.png` | Add Torrent dialog / a torrent downloading |
| `05-youtube-quality-picker.png` | YouTube quality-picker dialog (full build) |
| `06-browser-shields.png` | In-app browser with Shields (adblock) |
| `07-theme-settings.png` | Theme / Settings screen |

**Format:** PNG or JPG, portrait phone screenshots, any size — the build
script resizes everything to a common height automatically. Add, remove,
or rename freely; the script just picks up whatever's here in filename
order (numeric prefixes keep that order predictable).
